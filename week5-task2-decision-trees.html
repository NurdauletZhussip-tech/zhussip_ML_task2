Rules your code must follow, so that results can be compared:

  • Candidate thresholds for a feature are the midpoints between consecutive distinct sorted values; rows with x <= threshold go left.
  • A split is valid only if both children hold at least min_samples_leaf rows. Ties between equal gains go to the lower feature index, then the lower threshold.
  • A node becomes a leaf when it is pure, when depth == max_depth, or when no valid split exists. A leaf predicts its majority class (a tie goes to the smaller label).

3How deep should the tree be?6 pts

A tree that is allowed to grow until every leaf is pure can memorise the training set. In this part you measure how much that costs, using only the training split. The test split is not touched until step 3e.

from sklearn.model_selection import StratifiedKFold, cross_validate
from sklearn.tree import DecisionTreeClassifier

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=SEED)
model = DecisionTreeClassifier(criterion="entropy", max_depth=3, random_state=SEED)
scores = cross_validate(model, X_train, y_train, cv=cv, scoring="accuracy", return_train_score=True)
print(scores["train_score"].mean(), scores["test_score"].mean(), scores["test_score"].std())
